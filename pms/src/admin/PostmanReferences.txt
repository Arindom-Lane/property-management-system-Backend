I. ADMIN MODULE - POSTMAN

Base URL: http://localhost:3000/admin

1. Register Admin

Method: POST

URL: http://localhost:3000/admin/register

Body:
{
    "name":"Admin",
    "email":"admin@gmail.com",
    "password":"1234"
}

2. Login Admin

Method:POST

URL: http://localhost:3000/admin/login

Body:

{
    "email":"admin@gmail.com",
    "password":"1234"
}

Response:
{
    "access_token":"JWT_TOKEN"
}

must Copy this token for access profile.

Authorization:

Example:

Bearer eyJhbGciOiJIUzI1NiIsInR5cCI...

3. Get Profile

Method: GET

URL: http://localhost:3000/admin/profile

Headers:

Authorization: Bearer JWT_TOKEN

4. Update Profile

Method: PATCH

URL: http://localhost:3000/admin/profile

Headers:
Authorization: Bearer WT_TOKEN

Body:
{
    "name":"Admin Updated",
    "email":"adminupdated@gmail.com"
}

5. Change Password

Method: PATCH

URL: http://localhost:3000/admin/changepass

Headers:
Authorization: Bearer JWT_TOKEN

Body:
{
    "oldPassword":"1234",
    "newPassword":"5678"
}

6. Get All Admin

Method: GET

URL: http://localhost:3000/admin

Headers:
Authorization: Bearer JWT_TOKEN

7. Search Admin

Method: GET

URL: Search By Name: http://localhost:3000/admin/search?keyword=Eyamin

     Search By Email: http://localhost:3000/admin/search?keyword=eyamin@gmail.com

Headers:
Authorization: Bearer JWT_TOKEN

8. Get Admin By ID

Method: GET

URL: http://localhost:3000/admin/1

Headers:
Authorization: Bearer JWT_TOKEN

9. Delete Admin

Method: DELETE

URL: http://localhost:3000/admin/1

Headers:
Authorization: Bearer JWT_TOKEN

END OF ADMIN MODULE

VII. PROPERTY MODULE - POSTMAN

Base URL: http://localhost:3000/admin/property

Authorization
All APIs require: Authorization: Bearer JWT_TOKEN

1. Create Property

Method: POST

URL: http://localhost:3000/admin/property/create

Body:
{
    "unit_number":"A-101",
    "buildingId":1,
    "landlordId":1,
    "rent_amount":15000,
    "service_charge":2000,
    "has_parking":true,
    "parking_fee":1000,
    "listing_status":"for_rent",
    "status":"vacant"
}
Note:
listing_status values:
- not_listed
- for_rent
- for_sale

status values:
- vacant
- occupied
- sold

2. Get All Properties

Method: GET

URL: http://localhost:3000/admin/property/allproperties

3. Search Property

Method: GET

Search By Unit Number: http://localhost:3000/admin/property/search?keyword=A-101

Search By Created By: http://localhost:3000/admin/property/search?keyword=Admin

4. Get Property By ID

Method: GET

URL: http://localhost:3000/admin/property/find/1
