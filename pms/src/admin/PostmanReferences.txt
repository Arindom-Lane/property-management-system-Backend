I. ADMIN MODULE - POSTMAN

Base URL: http://localhost:3000/admin

1. Register Admin

Method: POST

URL: http://localhost:3000/admin/register

Body:
{
    "name":"Admin",
    "email":"admin@gmail.com",
    "password":"1234"
}

2. Login Admin

Method:POST

URL: http://localhost:3000/admin/login

Body:

{
    "email":"admin@gmail.com",
    "password":"1234"
}

Response:
{
    "access_token":"JWT_TOKEN"
}

must Copy this token for access profile.

Authorization:

Example:

Bearer eyJhbGciOiJIUzI1NiIsInR5cCI...

3. Get Profile

Method: GET

URL: http://localhost:3000/admin/profile

Headers:

Authorization: Bearer JWT_TOKEN

4. Update Profile

Method: PATCH

URL: http://localhost:3000/admin/profile

Headers:
Authorization: Bearer WT_TOKEN

Body:
{
    "name":"Admin Updated",
    "email":"adminupdated@gmail.com"
}

5. Change Password

Method: PATCH

URL: http://localhost:3000/admin/changepass

Headers:
Authorization: Bearer JWT_TOKEN

Body:
{
    "oldPassword":"1234",
    "newPassword":"5678"
}

6. Get All Admin

Method: GET

URL: http://localhost:3000/admin

Headers:
Authorization: Bearer JWT_TOKEN

7. Search Admin

Method: GET

URL: Search By Name: http://localhost:3000/admin/search?keyword=Eyamin

     Search By Email: http://localhost:3000/admin/search?keyword=eyamin@gmail.com

Headers:
Authorization: Bearer JWT_TOKEN

8. Get Admin By ID

Method: GET

URL: http://localhost:3000/admin/1

Headers:
Authorization: Bearer JWT_TOKEN

9. Delete Admin

Method: DELETE

URL: http://localhost:3000/admin/1

Headers:
Authorization: Bearer JWT_TOKEN

END OF ADMIN MODULE

IX. COMPLAINT MODULE - POSTMAN

Base URL: http://localhost:3000/admin/complaint

Authorization

Submit Complaint: NO token needed (open to Landlord / Tenant / Staff)

All other APIs require: Authorization: Bearer JWT_TOKEN

1. Submit Complaint

Method: POST

URL: http://localhost:3000/admin/complaint/submit

Headers:
No Authorization needed

Body:
{
    "filed_by_type":"TENANT",
    "filed_by_id":1,
    "against_type":"LANDLORD",
    "against_id":1,
    "description":"Landlord is not repairing the water pump for two weeks."
}

Note:
filed_by_type values:
- LANDLORD
- TENANT
- STAFF

against_type values:
- LANDLORD
- TENANT
- STAFF

against_id is optional. If the complaint is general (not against a specific person), remove the against_id line.

The filer (filed_by_id) and the target (against_id) must exist in the database, otherwise 404 Not Found.

2. Get All Complaints

Method: GET

URL: http://localhost:3000/admin/complaint/allcomplaints

Headers:
Authorization: Bearer JWT_TOKEN

3. Search Complaint

Method: GET

URL: Search By Description: http://localhost:3000/admin/complaint/search?keyword=water

     Search By Filer Type: http://localhost:3000/admin/complaint/search?keyword=TENANT

Headers:
Authorization: Bearer JWT_TOKEN

4. Get Complaints By Status

Method: GET

URL: http://localhost:3000/admin/complaint/status?status=PENDING

Headers:
Authorization: Bearer JWT_TOKEN

Note:
status values:
- PENDING
- IN_PROGRESS
- RESOLVED
- REJECTED

5. Get Complaints By Filer Type

Method: GET

URL: http://localhost:3000/admin/complaint/filer?filed_by_type=TENANT

Headers:
Authorization: Bearer JWT_TOKEN

Note:
filed_by_type values:
- LANDLORD
- TENANT
- STAFF

6. Get Complaint By ID

Method: GET

URL: http://localhost:3000/admin/complaint/find/1

Headers:
Authorization: Bearer JWT_TOKEN

7. Update Complaint (Admin Inspection)

Method: PATCH

URL: http://localhost:3000/admin/complaint/update/1

Headers:
Authorization: Bearer JWT_TOKEN

Body:
{
    "status":"IN_PROGRESS",
    "admin_note":"Notified the landlord, repair scheduled for Sunday."
}

Note:
status values:
- PENDING
- IN_PROGRESS
- RESOLVED
- REJECTED

admin_note is optional. The admin who updates the complaint is saved as reviewed_by automatically.

8. Delete Complaint

Method: DELETE

URL: http://localhost:3000/admin/complaint/delete/1

Headers:
Authorization: Bearer JWT_TOKEN

END OF COMPLAINT MODULE
