PROPERTY MANAGEMENT SYSTEM - STAFF API ROUTES
================================================

Base URL:
http://localhost:3000

AUTHENTICATION
--------------
For every route marked [AUTH], send this header:
Authorization: Bearer <access_token>

The token is obtained from POST /auth/login. The API does not use a global
prefix, so the URLs below are exactly the URLs to call.

Enum values:
- staff account status: active, deactive
- worker status: free, busy
- work-order status: pending, assigned, tenant_confirmed, complete
- issue status: OPEN, IN_PROGRESS, RESOLVED

------------------------------------------------
1. STAFF LOGIN (shared auth route)
------------------------------------------------

POST http://localhost:3000/auth/login
Body:
{
  "accountType": "staff",
  "email": "staff@example.com",
  "password": "testtest"
}

Success response (200):
{
  "message": "Login successful",
  "access_token": "<JWT_TOKEN>",
  "user": {
    "id": 1,
    "name": "John Staff",
    "email": "staff@example.com",
    "account_type": "staff"
  }
}

Possible errors:
- 401: {"message":"Invalid email or password"}
- 401: {"message":"Staff account is inactive"}
- 400: validation error when accountType, email, or password is invalid

16. LIST WORK ORDERS
------------------------------------------------

GET http://localhost:3000/staff/work-orders?status=pending&landlordId=2&dateFrom=2026-09-01&dateTo=2026-09-30&search=10&page=1&limit=10&sortOrder=DESC
[AUTH]
Body: none

this is based on this dto file
import {
  IsOptional,
  IsEnum,
  IsDateString,
  IsString,
  IsInt,
  Min,
} from 'class-validator';
import { Type } from 'class-transformer';
import { OrderStatus } from '../entities/work_order.entity';

export class FilterWorkOrderDto {
  @IsOptional()
  @IsEnum(OrderStatus)
  status?: OrderStatus;

  @IsOptional() @Type(() => Number) @IsInt() @Min(1) workerId?: number;
  @IsOptional() @Type(() => Number) @IsInt() @Min(1) propertyId?: number;
  @IsOptional() @Type(() => Number) @IsInt() @Min(1) landlordId?: number;
  @IsOptional() @Type(() => Number) @IsInt() @Min(1) tenantId?: number;
  @IsOptional() @IsDateString() dateFrom?: string;
  @IsOptional() @IsDateString() dateTo?: string;
  @IsOptional() @IsString() search?: string;
  @IsOptional() @Type(() => Number) @IsInt() @Min(1) page?: number = 1;
  @IsOptional() @Type(() => Number) @IsInt() @Min(1) limit?: number = 10;
  @IsOptional() @IsString() sortBy?: string = 'created_at';
  @IsOptional() @IsString() sortOrder?: 'ASC' | 'DESC' = 'DESC';
}


All query parameters are optional. Supported filters are status, landlordId,
dateFrom, dateTo, and search (searches the work-order ID). Defaults: page=1,
limit=10, sortOrder=DESC. Results include the landlord relation and work-order
fields; property, worker, tenant, issue, building, and review are not joined
by this list endpoint.

Success response (200):
{
  "data": [
    {
      "id": 10,
      "status": "pending",

      "created_by_id": 1,
      "labor_cost": 0,
      "materials_cost": 0,
      "additional_cost": 0,
      "created_at": "2026-09-05T04:36:38.000Z",
      "completed_at": null,
      "landlord": {"id": 2, "name": "Landlord One"}
    }
  ],
  "total": 1,
  "page": 1,

COMMON ERRORS
------------------------------------------------

Missing or invalid authentication:
401
{"message":"Invalid or expired token"}

Missing Bearer header:
401
{"message":"****** is required"}

Invalid numeric route/query parameter:
400
{"message":"Validation failed (numeric string is expected)"}

Missing record:
404
{"message":"<Record type> not found"}

Validation errors generally return HTTP 400 with a message array describing
the invalid fields.

IMPORTANT IMPLEMENTATION NOTES
------------------------------
1. The old POST /staff/login route is commented out and is not available.
   Use POST /auth/login with accountType="staff".
2. Protected routes verify that a JWT exists, but the current AuthGuard does
   not restrict a token to staff; any valid account token may pass the guard.
3. Entity responses can contain password_hash for staff records because the
   current service returns the entity directly. Treat that field as sensitive.
4. Numeric DTO fields require JSON numbers, not quoted strings, when sent in
   request bodies. Query parameters are converted by the DTO where applicable.
5. The examples use representative records. IDs, dates, relations, and counts
   depend on the current database contents.
6. The files CreateTransaction.dto.ts, FilterTransaction.dto.ts, worker.dto.ts,
   and LoginStaff.dto.ts were reviewed. CreateTransaction.dto.ts and
   FilterTransaction.dto.ts are not connected to any current StaffController
   route, worker.dto.ts is also unused by the controller, and LoginStaff.dto.ts
   belongs to the commented-out POST /staff/login route. Therefore none of
   those DTOs has a currently callable staff route in this document.

43. EDIT LOGGED-IN STAFF PROFILE
------------------------------------------------

PATCH http://localhost:3000/staff/profile
[AUTH]
Content-Type: application/json

The endpoint updates the staff member represented by the JWT. Do not send a
staff ID in the URL or body. Send only the fields that should change; all four
fields are optional, but at least one field is required.

Body:
{
  "name": "arino",
  "email": "arino@gmail.com",
  "phone": "00000000000",
  "password": "newpassword"
}

You can also send only one field:
{
  "name": "arino"
}

Password behavior:
- password is hashed with bcrypt before saving.
- password_hash is never returned in this response.
- the password must be at least 6 characters.

Success response (200):
{
  "id": 1,
  "name": "arino",
  "email": "arino@gmail.com",
  "phone": "00000000000",
  "status": "active",
  "created_at": "2026-09-05T04:36:38.000Z"
}

Possible errors:
- 400: {"message":"At least one profile field is required"}
- 400: validation error for invalid email, phone, name, or password
- 401: invalid or expired JWT
- 403: {"message":"Only staff can update a staff profile"}
- 403: {"message":"Staff email already exists"}
- 403: {"message":"Staff phone already exists"}
- 404: {"message":"Staff not found!"}
